Docs, launching

One transaction makes a coin

The coin opens on a bonding curve, and your first buy goes in before anyone else can. When the curve fills, the coin moves to a pool and its liquidity is locked for good.

// Launchpad
function launch(
  string name, string symbol, string uri,
  uint256 minTokensOut, uint256 wholeSupply,
  uint16 feeBps, uint16 holdersBps, uint16 burnBps,
  bool antiSnipe
) payable returns (address)

Docs, copy trading

Copy a wallet, not a screenshot
